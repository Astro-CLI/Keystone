# Core Layer Documentation

This directory contains all documentation related to the **Core Layer** of the network. This is the backbone of the SOYMSA enterprise network.

## Content

In this folder, you will find detailed information about:

-   **High-speed routing and switching:** The main routers and switches that form the core of the network.
-   **ISP (Internet Service Provider) information:** Details about the ISPs connected to the network, including BGP Autonomous System Numbers (ASNs) and IP address allocations. You can find this information in `ISPs.txt` and `isps.html`.
-   **Routing protocols:** Configurations and diagrams for BGP, OSPF, or any other routing protocols used at the core.
-   **Core network topology:** Diagrams and explanations of how the core is designed for high availability and performance.

As the project evolves, this directory will be updated with more specific documents, diagrams, and configuration guides related to the core layer.
