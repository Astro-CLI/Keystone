# Access Layer Documentation

This directory contains all documentation related to the **Access Layer** of the network.

## Content

In this folder, you will find detailed information about:

-   **End-user connectivity:** How devices like computers, printers, and IP phones connect to the network.
-   **Switch configurations:** VLAN assignments, port security, and other switch-level settings.
-   **Access control lists (ACLs):** Rules that filter traffic at the access layer.
-   **Physical layout diagrams:** Where the access switches and other hardware are physically located.

As the project evolves, this directory will be updated with more specific documents, diagrams, and configuration guides related to the access layer.
