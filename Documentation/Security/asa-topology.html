תיעוד הגדרות רשת ו-Security

ניהול תעבורה בין איזורי אבטחה ב-Cisco ASA

1. מבנה הטופולוגיה (Security Levels)

Outside (אדום)

Level: 0

איזור לא בטוח (ISP)

DMZ (ירוק)

Level: 50

איזור שרתים ציבוריים

Inside (כחול)

Level: 100

רשת פנימית מאובטחת

2. חוקי גישה (ACL)

כדי לאפשר כניסה מ-Outside (0) ל-DMZ (50), הגדרנו רשימת גישה מפורשת:

access-list OUTSIDE_IN extended permit tcp any host 200.101.255.1 eq www access-list OUTSIDE_IN extended permit icmp any any echo access-group OUTSIDE_IN in interface outside

חשוב: רמת אבטחה גבוהה לנמוכה (100 -> 50) מותרת אוטומטית, אלא אם קיים ACL חוסם.

3. ניתוב והפצה מחדש (Redistribution)

מכיוון שה-ASA לא מריץ BGP, נתב Movistar משמש כגשר בין ה-Red Cloud ל-Firewall:

! בנתב Movistar - העברת נתיבי BGP ל-EIGRP (לכיוון ה-ASA) router eigrp 10 redistribute bgp 10834 metric 10000 100 255 1 1500 ! בנתב Movistar - העברת נתיבי EIGRP ל-BGP (לכיוון הענן האדום) router bgp 10834 redistribute eigrp 10

4. הגדרות NAT ב-ASA

כדי למנוע תקלות תקשורת בין ה-Inside ל-DMZ, הגדרנו "Identity NAT" (אי-תרגום כתובות):

nat (inside,dmz) source static any any destination static any any

5. פקודות בדיקה חיוניות

  • show route - בדיקת טבלת הניתוב ב-ASA.
  • show eigrp neighbors - וידוא יחסי שכנות.
  • packet-tracer input outside icmp... - כלי הניתוח המרכזי.
  • inspect icmp - חובה בתוך ה-Policy Map כדי לאפשר פינגים.
