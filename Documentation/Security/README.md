# Security Documentation

This directory contains comprehensive documentation for SOYMSA's security infrastructure, including firewall configurations and network security policies.

## Contents

### asa-topology.html
A detailed technical documentation covering the Cisco ASA 5506-X firewall configuration in the SOYMSA network. Includes:

- **Network Security Levels**: Three-tier security model (Outside, DMZ, Inside)
- **Access Control Lists (ACL)**: Traffic rules and filtering policies
- **Routing & Redistribution**: EIGRP/BGP integration with Cisco ASA
- **NAT Configuration**: Network Address Translation policies
- **Troubleshooting Guide**: Essential commands for network diagnostics

**Language**: Hebrew (עברית)  
**Format**: Interactive HTML with Tailwind CSS styling
