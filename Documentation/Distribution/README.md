# Distribution Layer Documentation

This directory contains all documentation related to the **Distribution Layer** of the network. This layer acts as the middle ground between the high-speed core and the end-user access layer.

## Content

In this folder, you will find detailed information about:

-   **Policy-based connectivity:** How the distribution layer enforces network policies, such as routing policies and access control.
-   **Aggregation of access layer switches:** How the distribution layer connects multiple access layer switches together.
-   **Redundancy and load balancing:** How the distribution layer provides high availability for the access layer.
-   **VLAN routing:** How the distribution layer routes traffic between different VLANs.

As the project evolves, this directory will be updated with more specific documents, diagrams, and configuration guides related to the distribution layer.
